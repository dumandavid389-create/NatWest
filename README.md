# NatWest Banking App Prototype

A responsive, single-page banking dashboard concept built with plain HTML, CSS, and JavaScript. It includes a sample account overview, fictional transactions, spending categories, quick-action feedback, and a date that updates automatically.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Important

This is a non-functional visual prototype, not an official NatWest service. It uses fictional sample data, does not connect to real accounts, and cannot make payments. Do not enter real personal, login, or payment information.
